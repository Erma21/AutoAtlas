# AutoAtlas

Атлас автомобилей для начинающих и среднего уровня.  
Помогает разбираться в системах автомобиля, сравнивать компоненты и диагностировать симптомы.

## Возможности

- Просмотр систем автомобиля (двигатель, кузов, салон, багажник и др.)
- Сравнение компонентов
- Диагностика по симптомам
- Удобный интерфейс на SwiftUI

## Структура проекта

- `App/` — точка входа приложения
- `Models/` — модели данных
- `Views/` — экраны приложения
- `Services/` — загрузка данных
- `DesignSystem/` — тема и стили
- `Assets.xcassets/` — изображения и цвета

## Как запустить

1. Открой проект в Xcode
2. Выбери симулятор или реальное устройство
3. Нажми **Run** (`⌘R`)

## Технологии

- Swift
- SwiftUI
- Xcode
